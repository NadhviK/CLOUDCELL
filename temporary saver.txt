🛠️ Step-by-Step Setup Guide
Follow these steps to deploy and run the application on your computer:

1. Database Configuration
Open your MySQL Command Line Client, MySQL Workbench, or any database tool.
Execute the queries inside the 
schema.sql
 file.
This creates a database called cloudcell_db.
It creates all required tables: Customers, Packages, Reloads, Billing, BankDetails, and Admin.
It populates dummy data (sample customers, default packages, transaction logs, and a SuperAdmin account).
2. Opening the Project in NetBeans
Download and extract 
CloudCellApp.zip
.
Open NetBeans IDE.
Click File -> Open Project.
Browse to the extracted CloudCellApp folder (NetBeans will detect it as a Maven Web Project because it contains a pom.xml).
NetBeans will automatically download the required dependencies (MySQL connector, Servlet APIs, JSTL, JSON helpers) specified in the POM file.
3. Modifying Database Credentials
In NetBeans, expand the project tree: Source Packages -> com.cloudcell.dao.
Open 
DatabaseConnection.java
.
Edit the static variables for credentials:
java

private static final String USER = "root";
private static final String PASSWORD = "root"; // Replace with your MySQL password
Save the file.
4. Running the Web Application on Tomcat
Right-click on the CloudCellApp project in NetBeans and select Run (or click the Green Play button).
If prompted, select your installed Apache Tomcat server (Tomcat 9 or 10 supporting standard Javax Servlet specifications).
NetBeans will package the application as a WAR file, deploy it to Tomcat, and launch your default browser at: http://localhost:8080/CloudCellApp/
